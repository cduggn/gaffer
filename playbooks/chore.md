# Chore

Small, mechanical work. Keep it boring.

1. Make the change. If it repeats across many files, write a script that does it and commit the script's output, so a reviewer can rerun it.
2. Run `gaffer verify`.
3. If the work turns out to need design decisions, stop, record why in the bead, and relabel it `playbook:feature`.

Report: what changed and the verification result.
