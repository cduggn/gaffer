# Investigation

You own the answer. This is read-only. Do not change code.

1. Restate the question as something that can be shown true or false.
2. Read the code and history that bear on it. Run things when behavior is the question, rather than inferring it from source.
3. Cite every claim with a file and line, a command and its output, or a commit. Label anything you did not observe as inference.
4. If the question is a choice between options, give a recommendation and a short tradeoff table. Push back if the premise is wrong.
5. Post the answer with `bd comments add <id> --file answer.md` and hand off for review.

Report: the answer, its evidence, and what remains uncertain.
